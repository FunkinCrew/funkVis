# funkin.vis

`funkin.vis` is a haxelib for processing audio data into frequency data using FFT's with Radix-2 algorithm, created for Friday Night Funkin' by The Funkin' Crew Inc.

## Installation

`haxelib git funkin.vis https://github.com/FunkinCrew/funkVis`
